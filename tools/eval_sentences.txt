# The benchmark asr_eval.py reads. One line per probe: domain<TAB>text.
#
# Fifty sentences split across the three target domains, because a ranking is
# only as meaningful as what it was measured on. The earlier six-sentence probe
# could not separate the top checkpoints — the spread between models was 0.118
# against a standard error of 0.058 — and half of that noise came from a single
# sentence, "今天各地天氣多雲到晴", whose key words appear zero times in the
# corpus and which every model therefore garbles differently.
#
# Sentences are kept to roughly 10-30 characters. The splitter cuts at 120 BPE
# tokens, so staying under that keeps each take a single pass with no sentence
# joins, which is a separate problem measured separately.
#
# Vocabulary is deliberately mixed: some of these words the corpus has hundreds
# of examples of, some it has none. That is the point — the failure being
# tracked is word coverage, so a benchmark of only well-covered words would
# report a score that improves with nothing.
